              Mettre en ligne pour tous

              Pour que tous les visiteurs voient ce livre, ajoutez-le au fichier du site en trois gestes.

              1. Téléchargez les fichiers du livre, puis placez la couverture dans le dossier images/ et le PDF dans le dossier livres/, à côté de index.html.
              2. Copiez cette ligne de code.
              3. Dans index.html, collez-la dans le tableau LIVRES_PUBLICS (zone « À MODIFIER »), enregistrez, puis mettez le site en ligne.
